# Nerdy releases

Signed builds of the Nerdy app and the manifest its updater reads.

Install the APK from the latest release, or let an installed copy update itself
(Settings -> App updates). Every APK is signed with the same key as the app
already on the phone; one signed differently is rejected.

`nerdy-update.json` is generated by `release-github.sh` in the Nerdy source repo.
It is not edited by hand.
